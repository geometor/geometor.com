Installation & Workspace Setup¶

Python 3.13 & uv Environment Guide

GEOMETOR packages target modern Python 3.13+ and recommend uv for fast, reproducible virtual environments.

Installing Release Packages from PyPI¶

To install the core symbolic engine and golden-section analyzer into a fresh environment:

uv venv --python 3.13
        source .venv/bin/activate
        uv pip install geometor-model geometor-divine

Working from Source Repositories¶

Every repository under github.com/geometor follows a clean src/geometor/<repo_name>/ namespace package layout and can be cloned and synced directly with uv:

git clone https://github.com/geometor/model.git
        cd model
        uv sync
        uv run pytest

Building Book Codices Locally¶

GEOMETOR’s multi-track Book Codices use Sphinx with the foundation Scriptorium theme from photon-platform/publish:

uv tool install git+https://github.com/photon-platform/publish.git
        publish build
